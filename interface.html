No Replay NTSL, cada input selecionado é aplicado ao código. A busca contabiliza resultados conforme o objetivo escolhido.
Campos excluídos das entradas do modelo Classe, tipo de ordem e rótulo de amplitude são protegidos. No ensemble, exclusões adicionais desativam árvores dependentes. No Replay NTSL, se o código usar um campo excluído, a busca aponta o conflito. O alvo e o horário continuam sendo calculados.
Use {} para aplicar os valores do código. Exemplo de ajuste: {"p_Lote": 2}.
