## Cobertura da v5.8 e controles

| Cenário | Replays locais | Resultado do controle com a estratégia completa |
|---|---|---|
| Espera após stop na barra de entrada | 0 casos em 21/10, 2 em 26/10 | Entrada e stop na barra 10, saída gravada no fechamento e nova solicitação na 13 |
| Uma entrada por candle | 0 solicitações duplicadas por rótulo em ambos | Extra comprada com contexto da barra 9 vê `ultima_entrada=9` e `pode=0` |
| Limite diário | Máximos de 6 e 10; em 26/10, dois candidatos em posição zerada e no horário com contador já no teto | Dois pedidos em cada pregão no caso de limite 2, com primeira barra da segunda sessão fora da janela de entrada |
| Reinício do limite | Cada execução real contém um único pregão | Reinício normal em duas sessões e caso de risco com solicitação na primeira barra |
| Cancelamento de pendente com posição zerada | Nenhuma solicitação de cancelamento nos dois dias | Ordem limite sintética pré-carregada é cancelada na barra 1, sem preenchimento |
| Stop-limit com gap e `Abs(Position)` | 2 e 5 disparos; todos com saída no mesmo candle de disparo | Entrada 1.005 × 2, stop 655 com limite 605, abertura abaixo do limite na barra 11 e saída de dois contratos a 605 na 12 |
| `Power`, modo banda 1 e referências `[1]` | Banda 0 e `p_Exec_Tick=0` na rodada real | Modo 1 confere raiz da média do quadrado da distância até VWAP. `Trades[1]` auditado como leitura. Média e desvio de Volume no Z-score conferidos sobre as 20 barras anteriores. |

**Achado controlado do simulador:** se a primeira barra da sessão solicita uma entrada, o preenchimento na abertura seguinte dispara uma avaliação extra com o contexto da primeira barra. Nesse contexto, `Date <> Date[1]` continua verdadeiro. A v5.8 volta a escrever zero no contador, embora a solicitação anterior tenha incrementado a contagem. Com limite sintético de dois, o segundo pregão chegou a três solicitações. O primeiro evento relevante é a avaliação extra de contexto 19, com posição 2 e `entradas=0` após a solicitação da barra 19. Os dois pregões reais não cobriram essa sequência. A equivalência com o Profit e uma eventual correção dependem de confirmação nativa. [Recortes sintéticos em ordem de emissão](controles_v5_8.csv)

## Comandos locais e comparação nativa

Use um destino novo para cada execução. O comparador separa as camadas, usa a ordem de emissão dentro do rótulo de contexto NTSL e registra a primeira diferença de cada camada. Para preenchimentos usa os horários da exportação, sem deslocamento global. Empates no minuto do Profit são organizados pelo número de operação, com entrada antes da saída. Essa ordenação serve à comparação por minuto.

```powershell
$evid = 'docs/colaboracao/evidencias/WINZ26_v5_8_validacao_20261021_20261026_v1'
$comum = @('--segundos','60','--formato','ohlc','--tick','5','--valor-ponto','0.2',
  '--volume-financeiro-ntsl','--agressao-referencia-injetada','--vwap-continuo-lacunas',
  '--avaliacao-pos-preenchimento','--rastrear-ordens')
py -3.11 estrategia.py --csv $barrasPreparadas `
  --ntsl estrategias/execucao/Modelo_Unificado_v5_8.ntsl `
  --inputs "$evid/inputs_v5_8.json" --saida $original @comum
py -3.11 estrategia.py --csv $barrasPreparadas `
  --ntsl "$evid/Modelo_Unificado_v5_8_Auditoria_simulador_v1_0.ntsl" `
  --inputs "$evid/inputs_v5_8.json" --saida $auditoria @comum

# Quando as exportações v5.8 do Profit chegarem:
py -3.11 tools/comparar_v5_8.py --data $dia --aquecimento 63 `
  --console-profit $consoleProfit --operacoes-profit $operacoesProfit `
  --barras-profit $barrasProfit --barras-preparadas $barrasPreparadas `
  --console-simulador "$auditoria/console.csv" --candles-simulador "$auditoria/candles.csv" `
  --execucoes-simulador "$auditoria/execucoes.csv" --saida $comparacao

$antes = 'docs/colaboracao/evidencias/WINZ26_v5_7_persistencia_20261026_v1'
py -3.11 estrategia.py --csv "$antes/candles_sinteticos.csv" `
  --ntsl "$evid/sonda_persistencia_simulador_v2_0.ntsl" --saida $sonda `
  --segundos 60 --formato ohlc --avaliacao-pos-preenchimento --rastrear-ordens
py -3.11 -m pytest -q tests/test_v5_8_paridade.py
py -3.11 -m pytest -q
```

function q_Flag(p_Valor : Boolean): Integer;
begin
  if p_Valor then Result := 1
  else Result := 0;
end;


begin
  q_Log := (Date = 1261021) or (Date = 1261026);
  if q_Log then q_Seq := q_Seq + 1;
  { ================= Indicadores (candle atual) ================= }
  v_VWAP_Diaria    := VWAP(1);
  v_Dist_VWAP      := Close - v_VWAP_Diaria;
  v_Dist_VWAP_Quad := v_Dist_VWAP * v_Dist_VWAP;

  if p_Modo_Banda = 1 then
    v_Desvio_Padrao := Power(Media(p_Periodo_Desvio, v_Dist_VWAP_Quad), 0.5)
  else
    v_Desvio_Padrao := StdDevs(Close, p_Periodo_Desvio);

  v_Banda_Superior := v_VWAP_Diaria + (p_Desvio_VWAP * v_Desvio_Padrao);
  v_Banda_Inferior := v_VWAP_Diaria - (p_Desvio_VWAP * v_Desvio_Padrao);

=== estrategias/execucao/Modelo_Unificado_v5_8.ntsl ===

{ Modelo Unificado Refatorado v5.8 - WIN / ProfitPro                          }
{ Base: v5.7. Mudancas:                                                         }
{  1. Densidade (Trades) so bloqueia ENTRADA e usa candle fechado no tick a tick }
{  2. Sinal de entrada usa candle FECHADO (p_Exec_Tick = 1)                     }
{  3. Uma entrada por candle + espera de N candles apos cada saida              }
{  4. Folga do stop-limite padrao 50 pts (era 5 = 1 tick)                       }
{  5. Saidas usam a posicao real (Abs(Position)), nao o lote fixo               }
{  6. Cancela ordem pendente que sobrou com o robo zerado                       }
{  7. Aquecimento dos indicadores (CurrentBar)                                  }
{  8. Z-score do volume contra os 20 candles ANTERIORES                         }
{  9. Banda opcional pelo desvio em torno da VWAP (p_Modo_Banda = 1)            }
{ 10. Horarios e janelas de noticia parametrizados; limite de entradas por dia  }
{                                                                               }
{ p_Exec_Tick: 1 = automacao / replay tick a tick                               }
{              0 = backtest e OTIMIZADOR (execucao por barra fechada)           }
{ Com os dois modos a entrada ocorre no inicio do candle seguinte ao sinal,     }
{ entao backtest e execucao real ficam equivalentes.                            }

input
  p_Exec_Tick(1);
  p_Periodo_ATR(14);
  p_Periodo_Regime_ATR(50);
  p_Desvio_VWAP(2.1);
  p_Modo_Banda(0);           { 0 = StdDevs(Close) como v5.7; 1 = desvio em torno da VWAP }
  p_Periodo_Desvio(20);
  p_ZScore_Vol(1.5);
  p_Stop_Pontos(350);
  p_Alvo_Pontos(400);
  p_MinimoTrades(100);
  p_Lote(5);
  p_Offset_Limite_Stop(50);
  p_Barras_Espera(3);        { candles sem nova entrada apos uma saida }
  p_Max_Entradas_Dia(10);
  p_Hora_Inicio(0915);
  p_Hora_Fim_Entradas(1645);
  p_Hora_Zeragem(1700);
  p_Noticia1_Ini(1025);      { 0 = janela desligada }
  p_Noticia1_Fim(1035);
  p_Noticia2_Ini(1425);
  p_Noticia2_Fim(1435);
  p_Zerar_Na_Noticia(1);     { 1 = zera na janela (como v5.7); 0 = so bloqueia entradas }

var
  v_VWAP_Diaria        : Float;
  v_Dist_VWAP          : Float;
  v_Dist_VWAP_Quad     : Float;
  v_Desvio_Padrao      : Float;
  v_Banda_Superior     : Float;
  v_Banda_Inferior     : Float;
  v_TrueRange          : Float;
  v_ATR                : Float;
  v_Media_ATR          : Float;
  v_Saldo_Agressao     : Float;
  v_Media_Volume       : Float;
  v_Desvio_Volume      : Float;
  v_Volume_ZScore      : Float;
  v_Regime_Mercado     : Integer;
  v_Sinal_Compra       : Boolean;
  v_Sinal_Venda        : Boolean;
  v_Compra_Conf        : Boolean;
  v_Venda_Conf         : Boolean;
  v_Densidade_OK       : Boolean;
  v_Aquecido           : Boolean;
  v_Na_Noticia         : Boolean;
  v_Pregao_Ativo       : Boolean;
  v_Zerar              : Boolean;
  v_Pode_Entrar        : Boolean;
  v_Posicionado        : Boolean;
  v_Estava_Posicionado : Boolean;
  v_Barra_Ult_Entr     : Integer;
  v_Barra_Ult_Saida    : Integer;
  v_Entradas_Dia       : Integer;
  v_Qtd                : Integer;

begin
  { ================= Indicadores (candle atual) ================= }
  v_VWAP_Diaria    := VWAP(1);
  v_Dist_VWAP      := Close - v_VWAP_Diaria;
  v_Dist_VWAP_Quad := v_Dist_VWAP * v_Dist_VWAP;

  if p_Modo_Banda = 1 then
    v_Desvio_Padrao := Power(Media(p_Periodo_Desvio, v_Dist_VWAP_Quad), 0.5)
  else
    v_Desvio_Padrao := StdDevs(Close, p_Periodo_Desvio);

  v_Banda_Superior := v_VWAP_Diaria + (p_Desvio_VWAP * v_Desvio_Padrao);
  v_Banda_Inferior := v_VWAP_Diaria - (p_Desvio_VWAP * v_Desvio_Padrao);

  v_TrueRange      := TrueRange;
  v_ATR            := Media(p_Periodo_ATR, v_TrueRange);
  v_Media_ATR      := Media(p_Periodo_Regime_ATR, v_ATR);
  v_Saldo_Agressao := AgressionVolBalance;

  v_Media_Volume   := Media(20, Volume);
  v_Desvio_Volume  := StdDevs(Volume, 20);

  { z-score do candle atual contra os 20 candles anteriores }
  if v_Desvio_Volume[1] > 0 then
    v_Volume_ZScore := (Volume - v_Media_Volume[1]) / v_Desvio_Volume[1]
  else
    v_Volume_ZScore := 0;

  { 1 = tendencia; 2 = reversao por exaustao; 0 = ruido/bloqueado }
  if (v_ATR > v_Media_ATR)
     and (Abs(Close - v_VWAP_Diaria) > (1.2 * v_Desvio_Padrao)) then
    v_Regime_Mercado := 1
  else if ((Low <= v_Banda_Inferior) or (High >= v_Banda_Superior))
          and (v_Volume_ZScore > p_ZScore_Vol) then
    v_Regime_Mercado := 2
  else
    v_Regime_Mercado := 0;

  v_Sinal_Compra :=
    ((v_Regime_Mercado = 1) and (Close > v_VWAP_Diaria)
     and (v_Saldo_Agressao > 0) and (v_Volume_ZScore > p_ZScore_Vol))
    or
    ((v_Regime_Mercado = 2) and (Low <= v_Banda_Inferior)
     and (v_Saldo_Agressao > 0));

  v_Sinal_Venda :=
    ((v_Regime_Mercado = 1) and (Close < v_VWAP_Diaria)
     and (v_Saldo_Agressao < 0) and (v_Volume_ZScore > p_ZScore_Vol))
    or
    ((v_Regime_Mercado = 2) and (High >= v_Banda_Superior)
     and (v_Saldo_Agressao < 0));

  { ================= Sinal confirmado (candle fechado) ================= }
  if p_Exec_Tick = 1 then
  begin
    v_Compra_Conf  := v_Sinal_Compra[1];
    v_Venda_Conf   := v_Sinal_Venda[1];
    v_Densidade_OK := Trades[1] > p_MinimoTrades;
  end
  else
  begin
    v_Compra_Conf  := v_Sinal_Compra;
    v_Venda_Conf   := v_Sinal_Venda;
    v_Densidade_OK := Trades > p_MinimoTrades;
  end;

  v_Aquecido := CurrentBar > (p_Periodo_ATR + p_Periodo_Regime_ATR + p_Periodo_Desvio + 2);

  { ================= Controle de estado ================= }
  if Date <> Date[1] then
    v_Entradas_Dia := 0;

  v_Posicionado := IsBought or IsSold;
  if v_Estava_Posicionado and (not v_Posicionado) then
    v_Barra_Ult_Saida := CurrentBar;

  { ================= Filtros de horario ================= }
  v_Na_Noticia :=
    ((p_Noticia1_Ini > 0) and (Time >= p_Noticia1_Ini) and (Time <= p_Noticia1_Fim))
    or
    ((p_Noticia2_Ini > 0) and (Time >= p_Noticia2_Ini) and (Time <= p_Noticia2_Fim));

  v_Pregao_Ativo := (Time >= p_Hora_Inicio) and (Time <= p_Hora_Zeragem);

  v_Zerar := (not v_Pregao_Ativo)
             or (v_Na_Noticia and (p_Zerar_Na_Noticia = 1));

  v_Pode_Entrar := v_Pregao_Ativo
                   and (Time <= p_Hora_Fim_Entradas)
                   and (not v_Na_Noticia)
                   and v_Densidade_OK
                   and v_Aquecido
                   and (CurrentBar <> v_Barra_Ult_Entr)
                   and (CurrentBar >= v_Barra_Ult_Saida + p_Barras_Espera)
                   and (v_Entradas_Dia < p_Max_Entradas_Dia);

  v_Qtd := Abs(Position);
  if v_Qtd = 0 then
    v_Qtd := p_Lote;

  { ================= Ordens ================= }
  if v_Zerar then
  begin
    if IsBought then
      SellToCoverAtMarket(v_Qtd)
    else if IsSold then
      BuyToCoverAtMarket(v_Qtd)
    else if HasPendingOrders then
      CancelPendingOrders;
  end
  else if IsBought then
  begin
    SellToCoverLimit(BuyPrice + p_Alvo_Pontos, v_Qtd);
    SellToCoverStop(BuyPrice - p_Stop_Pontos,
                    BuyPrice - p_Stop_Pontos - p_Offset_Limite_Stop,
                    v_Qtd);
  end
  else if IsSold then
  begin
    BuyToCoverLimit(SellPrice - p_Alvo_Pontos, v_Qtd);
    BuyToCoverStop(SellPrice + p_Stop_Pontos,
                   SellPrice + p_Stop_Pontos + p_Offset_Limite_Stop,
                   v_Qtd);
  end
  else if v_Pode_Entrar then
  begin
    if HasPendingOrders then
      CancelPendingOrders
    else if v_Compra_Conf then
    begin
      BuyAtMarket(p_Lote);
      v_Barra_Ult_Entr := CurrentBar;
      v_Entradas_Dia   := v_Entradas_Dia + 1;
    end
    else if v_Venda_Conf then
    begin
      SellShortAtMarket(p_Lote);
      v_Barra_Ult_Entr := CurrentBar;
      v_Entradas_Dia   := v_Entradas_Dia + 1;
    end;
  end
  else if HasPendingOrders and (CurrentBar <> v_Barra_Ult_Entr) then
    CancelPendingOrders;

  v_Estava_Posicionado := v_Posicionado;
end;

"""Compara a auditoria v5.8 no Profit e no simulador pelo contexto NTSL."""

import argparse
import csv
import json
from collections import defaultdict
from decimal import Decimal
from itertools import zip_longest
from pathlib import Path

import pandas as pd

try:
    from tools.comparar_paridade_mesmas_barras import compare_same_bars
    from tools.comparar_paridade_profit_win import (
        compare_operations, local_round_trips, normalize_bars, profit_round_trips,
        read_local_bars, read_profit, read_profit_operations, sha256, target_day,
    )
except ModuleNotFoundError:
    from comparar_paridade_mesmas_barras import compare_same_bars
    from comparar_paridade_profit_win import (
        compare_operations, local_round_trips, normalize_bars, profit_round_trips,
        read_local_bars, read_profit, read_profit_operations, sha256, target_day,
    )


def console_lines(path, native):
    if native:
        content = path.read_bytes()
        try:
            return content.decode("utf-8-sig").splitlines()
        except UnicodeDecodeError:
            return content.decode("cp1252").splitlines()
    with path.open(encoding="utf-8-sig", newline="") as stream:
        return [row["mensagem"] for row in csv.DictReader(stream)]


def audit_by_label(lines, day, native):
    grouped = defaultdict(list)
    day_code = int(day.replace("-", "")) - 19000000
    last_seq = None
    for line in lines:
        if not line.strip().startswith("V58;"):
            continue
        _, event, *raw_fields = line.strip().split(";")
        fields = {}
        for item in raw_fields:
            name, value = item.split("=", 1)
            fields[name] = Decimal(value.replace(".", "").replace(",", ".") if native else value)
        if fields["data"] != day_code:
            continue
        seq = int(fields["seq"])
        if event == "AVALIACAO":
            if last_seq is not None and seq <= last_seq:
                raise ValueError("Sequência reiniciada. Exporte somente uma execução do dia.")
            last_seq = seq
        elif seq != last_seq:
            raise ValueError("Solicitação sem avaliação correspondente em ordem de console.")
        hhmm = int(fields["hora"])
        label = f"{hhmm//100:02d}:{hhmm%100:02d}"
        grouped[label].append((event, fields))
    if not grouped:
        raise ValueError(f"Nenhuma mensagem V58 para {day}.")
    return grouped


def compare_audit(profit, simulator, labels, layer, tolerances):
    is_evaluation = layer != "solicitacoes"
    first = None
    compared = differing = 0
    for label in sorted(labels):
        left = [event for event in profit.get(label, []) if (event[0] == "AVALIACAO") == is_evaluation]
        right = [event for event in simulator.get(label, []) if (event[0] == "AVALIACAO") == is_evaluation]
        for rank, (p, s) in enumerate(zip_longest(left, right), 1):
            compared += 1
            field = None
            if p is None or s is None or p[0] != s[0]:
                field = "evento"
            else:
                field = next((name for name, tolerance in tolerances.items()
                              if name in p[1] or name in s[1]
                              if name not in p[1] or name not in s[1]
                              or abs(p[1][name] - s[1][name]) > tolerance), None)
            if field:
                differing += 1
                if first is None:
                    def evidence(record):
                        if record is None:
                            return None
                        event, values = record
                        return {"evento": event, "seq": int(values["seq"]), "barra_contexto": int(values["barra"]),
                                "valor": str(values[field]) if field in values else None}
                    first = {"hora_barra_contexto": label, "ordem_na_camada": rank, "campo": field,
                             "profit": evidence(p), "simulador": evidence(s)}
    return {"comparados": compared, "divergentes": differing, "primeira_divergencia": first}


def compare_fills(operations, fills, candles):
    profit = []
    for row in operations.sort_values("numero_operacao").itertuples(index=False):
        entry_side = "long" if row.lado == "C" else "short"
        profit.extend([
            (row.entrada.isoformat(), entry_side, row.quantidade, row.preco_entrada),
            (row.saida.isoformat(), "exit_" + entry_side, row.quantidade, row.preco_saida),
        ])
    profit.sort(key=lambda row: row[0])
    stamps = pd.Series(pd.to_datetime(candles["timestamp"]).array, index=candles["indice"])
    simulator = [(stamps.loc[int(row.barra) - 1].isoformat(), row.acao, row.quantidade, row.preco)
                 for row in fills.itertuples(index=False)]
    first = next(({"ordem": i, "profit": p, "simulador": s}
                  for i, (p, s) in enumerate(zip_longest(profit, simulator), 1) if p != s), None)
    return {"profit": len(profit), "simulador": len(simulator), "primeira_divergencia": first,
            "criterio_empate_profit": "Número da operação e entrada antes da saída; precisão da exportação."}


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    for name in ("console-profit", "operacoes-profit", "barras-profit", "barras-preparadas",
                 "console-simulador", "candles-simulador", "execucoes-simulador", "saida"):
        parser.add_argument("--" + name, type=Path, required=True)
    parser.add_argument("--data", required=True)
    parser.add_argument("--aquecimento", type=int, default=63)
    args = parser.parse_args()
    if args.saida.exists():
        parser.error("A saída já existe.")
    profit = audit_by_label(console_lines(args.console_profit, True), args.data, True)
    motor = audit_by_label(console_lines(args.console_simulador, False), args.data, False)
    if args.aquecimento < 0:
        parser.error("Aquecimento deve ser não negativo.")
    candles = pd.read_csv(args.candles_simulador)
    eligible = candles.loc[candles["barras_no_segmento"] > args.aquecimento]
    labels = {stamp[11:16] for stamp in eligible["timestamp"].astype(str) if stamp.startswith(args.data)}
    if not labels:
        parser.error("Nenhuma barra elegível.")
    original = target_day(normalize_bars(read_profit(args.barras_profit), "Data"), args.data)
    prepared = target_day(normalize_bars(read_local_bars(args.barras_preparadas), "timestamp"), args.data)
    bars = compare_same_bars(original, prepared)
    layers = {
        "sinais": dict.fromkeys(("compra", "venda", "regime", "densidade", "aquecido"), 0),
        "indicadores": dict.fromkeys(("vwap", "atr", "media_atr", "desvio_banda", "zvolume",
                                     "media_volume_1", "desvio_volume_1"), Decimal("0.01")),
        "posicao_estado": dict.fromkeys(("posicao", "preco_medio", "anterior", "pode", "entradas",
                                        "pendentes", "zerar"), 0),
        "solicitacoes": dict.fromkeys(("qtd", "gatilho", "limite"), 0),
    }
    profit_fills = profit_round_trips(read_profit_operations(args.operacoes_profit, args.data))
    fills = pd.read_csv(args.execucoes_simulador)
    motor_fills = local_round_trips(fills, candles)
    report = {
        "data": args.data,
        "barras": bars,
        "aquecimento_por_segmento": args.aquecimento,
        "rotulos_elegiveis": len(labels),
        "criterio": "Ordem de emissão da camada no mesmo rótulo de contexto. Execuções usam horários da exportação.",
        "camadas": {layer: compare_audit(profit, motor, labels, layer, fields) for layer, fields in layers.items()},
        "preenchimentos": compare_fills(profit_fills, fills, candles),
        "operacoes": compare_operations(profit_fills, motor_fills),
        "sha256_fontes": {key: sha256(path) for key, path in vars(args).items()
                          if isinstance(path, Path) and key != "saida"},
    }
    with args.saida.open("x", encoding="utf-8") as stream:
        json.dump(report, stream, indent=2, ensure_ascii=False)
        stream.write("\n")


if __name__ == "__main__":
    main()
