## Sequência e resultado

Em todas as sondas, a avaliação 1 de **10:51** começou zerada e solicitou a entrada a mercado. A avaliação 2 conservou o rótulo 10:51 e observou posição −1 em G3/G4 ou +1 na 03. A execução da entrada está registrada às **10:52:00**, pelo preço de abertura de 10:52. A avaliação 3, no contexto **10:52**, enviou uma única proteção. Em **10:53** e **10:54**, `HasPendingOrders=1` e a posição seguia aberta. Em **10:55**, a avaliação 6 observou posição e pendências zeradas, e o CSV registrou a saída às **10:55:00**. As avaliações até 10:58 ficaram zeradas, sem solicitações de limpeza ou de saída a mercado concorrente. O console registra a existência de pendências e a mudança de posição. O CSV informa uma operação por sonda, com horário ao segundo e preços de execução.

A barra de **10:55** tem abertura **+220**, máxima **+445**, mínima **−875** e fechamento **−260**, em pontos relativos à entrada. As barras de 10:53 e 10:54 ficam aquém dos níveis solicitados e dos candidatos na grade. Em 10:55, G3 exigia uma recompra abaixo da mínima pelo preço bruto e G4 exigia um gatilho acima da máxima pelo preço bruto. Os dois preenchimentos são compatíveis com o tick de 5 mais próximo. Como os dois ajustes de recompra aproximaram a ordem do preço, os exemplos também são compatíveis com arredondamento na direção do mercado. A rodada identifica nível efetivo no comportamento observado e deixa em aberto se o ajuste ocorre no cadastro ou na avaliação do toque. ## Reprodução e fontes

O extrator versionado confere os originais e os recortes independentes antes de executar novos replays. Use a raiz do repositório e destinos novos. `$originais` é a pasta local que contém os 12 anexos e os três CSVs de barras. `$barras` é a base preparada identificada em `fontes_barras.csv`. `$replays` deve ficar fora do Git. O script cria uma cópia local dos NTSLs para adaptar somente a formatação das mensagens e registra hashes dos insumos. O painel do Profit mostra `p_Alvo=877` em G3 e `p_Gatilho=447` com `p_Limite=1000` em G4. Em ambas, use `p_Data=1261026`, `p_Entrada=1051`, `p_Protecao=1052`, `p_Cancela=1056`, `p_Zera=1057` e `p_Fim=1058`. A configuração efetiva da 03 consta no passo a passo.

~~~powershell
py -3.11 -m pip install pymupdf
py -3.11 -m tools.publicar_grade_g3_g4_03_profit --originais $originais --barras $barras --replays $replays --saida $saida
py -3.11 -m pytest -q
~~~

Os oito replays usaram `--formato ohlc --segundos 60 --tick 5 --valor-ponto 0.2 --avaliacao-pos-preenchimento --protecoes-ate-cancelar --rastrear-ordens`. As variantes marcadas `flag_venda` também usaram `--ajuste-tick-saidas-venda`. A suíte local passou com **130 testes** e 12 avisos já conhecidos de fuso do pandas. As regressões privadas completas de v5.7/v5.8 são as da rodada anterior. O alcance desta rodada são as sondas G3/G4/03 com o mesmo motor. As capturas de Negócios, Preços e Ofertas têm outro nível de detalhe. A conferência aqui usa a sequência das avaliações, as barras exportadas e as operações de cada backtest. Esses arquivos não fornecem a aceitação da ordem stop-limit nem resolvem a sequência intrabar de 10:15. { G3: recompra limite fora da grade. Somente Backtest OHLC. }
input
  p_Data(1261026);
  p_Entrada(1051);
  p_Protecao(1052);
  p_Cancela(1056);
  p_Zera(1057);
  p_Fim(1058);
  p_Alvo(877);

var
  v_Seq, v_Pendentes : Integer;
  v_EntradaEnviada, v_ProtecaoEnviada, v_Cancelou, v_Zerou : Boolean;
  v_Limite : Float;

begin
  if (Date = p_Data) and (Time >= p_Entrada) and (Time <= p_Fim) then
  begin
    v_Seq := v_Seq + 1;
    if HasPendingOrders then v_Pendentes := 1 else v_Pendentes := 0;
    ConsoleLog("GRADE_G3;AVALIACAO"
      + ";data=" + FloatToString(Date, 0)
      + ";hora=" + FloatToString(Time, 0)
      + ";barra=" + FloatToString(CurrentBar, 0)
      + ";seq=" + FloatToString(v_Seq, 0)
      + ";posicao=" + FloatToString(PositionQty, 0)
      + ";pendentes=" + FloatToString(v_Pendentes, 0)
      + ";abertura=" + FloatToString(Open, 0)
      + ";maxima=" + FloatToString(High, 0)
      + ";minima=" + FloatToString(Low, 0)
      + ";fechamento=" + FloatToString(Close, 0), clYellow);

    if (Time = p_Entrada) and not v_EntradaEnviada and not HasPosition and not HasPendingOrders then
    begin
      v_EntradaEnviada := True;
      ConsoleLog("GRADE_G3;SOLICITA_VENDA;seq=" + FloatToString(v_Seq, 0), clYellow);
      SellShortAtMarket(1);
    end;

    if (Time = p_Protecao) and IsSold and not v_ProtecaoEnviada then
    begin
      v_ProtecaoEnviada := True;
      v_Limite := SellPrice - p_Alvo;
      ConsoleLog("GRADE_G3;SOLICITA_ALVO;seq=" + FloatToString(v_Seq, 0)
        + ";base=" + FloatToString(SellPrice, 0)
        + ";limite=" + FloatToString(v_Limite, 0), clYellow);
      BuyToCoverLimit(v_Limite, 1);
    end;

    if (Time = p_Cancela) and HasPendingOrders and not v_Cancelou then
    begin
      v_Cancelou := True;
      ConsoleLog("GRADE_G3;SOLICITA_CANCELAMENTO_LIMPEZA;seq=" + FloatToString(v_Seq, 0), clYellow);
      CancelPendingOrders;
    end;

    if (Time = p_Zera) and HasPosition and not v_Zerou then
    begin
      v_Zerou := True;
      ConsoleLog("GRADE_G3;SOLICITA_ZERAGEM_LIMPEZA;seq=" + FloatToString(v_Seq, 0), clYellow);
      ClosePosition;
    end;
  end;
end;

===== docs/colaboracao/evidencias/WINZ26_v5_8_protecoes_ate_cancelar_20261026_v1/sonda_prioridade_mercado_protecao_profit_v1_0.ntsl =====
{ Sonda de prioridade: uma perna por execução. Somente Backtest OHLC. }
input
  p_Data(1261026);
  p_Entrada(1051);
  p_Protecao(1052);
  p_EnvioMercado(1054);
  p_Limpeza(1056);
  p_Fim(1058);
  p_Perna(1);
  p_SaidaMercado(1);
  p_Alvo(430);
  p_Stop(795);
  p_Folga(100);

var
  v_Seq, v_Pendentes : Integer;
  v_EntradaEnviada, v_ProtecaoEnviada, v_MercadoEnviado, v_LimpezaEnviada : Boolean;
  v_Limite, v_Gatilho : Float;

begin
  if (Date = p_Data) and (Time >= p_Entrada) and (Time <= p_Fim) then
  begin
    v_Seq := v_Seq + 1;
    if HasPendingOrders then v_Pendentes := 1 else v_Pendentes := 0;
    ConsoleLog("PRIORIDADE;AVALIACAO"
      + ";data=" + FloatToString(Date, 0)
      + ";hora=" + FloatToString(Time, 0)
      + ";barra=" + FloatToString(CurrentBar, 0)
      + ";seq=" + FloatToString(v_Seq, 0)
      + ";posicao=" + FloatToString(PositionQty, 0)
      + ";pendentes=" + FloatToString(v_Pendentes, 0)
      + ";abertura=" + FloatToString(Open, 0)
      + ";maxima=" + FloatToString(High, 0)
      + ";minima=" + FloatToString(Low, 0)
      + ";fechamento=" + FloatToString(Close, 0), clYellow);

    if (Time = p_Entrada) and not v_EntradaEnviada and not HasPosition and not HasPendingOrders then
    begin
      v_EntradaEnviada := True;
      ConsoleLog("PRIORIDADE;SOLICITA_COMPRA;seq=" + FloatToString(v_Seq, 0), clYellow);
      BuyAtMarket(1);
    end;

    if (Time = p_Protecao) and IsBought and not v_ProtecaoEnviada then
    begin
      v_ProtecaoEnviada := True;
      if p_Perna = 1 then
      begin
        v_Limite := BuyPrice + p_Alvo;
        ConsoleLog("PRIORIDADE;SOLICITA_ALVO;seq=" + FloatToString(v_Seq, 0)
          + ";limite=" + FloatToString(v_Limite, 0), clYellow);
        SellToCoverLimit(v_Limite, 1);
      end
      else if p_Perna = 2 then
      begin
        v_Gatilho := BuyPrice - p_Stop;
        v_Limite := v_Gatilho - p_Folga;
        ConsoleLog("PRIORIDADE;SOLICITA_STOP;seq=" + FloatToString(v_Seq, 0)
          + ";gatilho=" + FloatToString(v_Gatilho, 0)
          + ";limite=" + FloatToString(v_Limite, 0), clYellow);
        SellToCoverStop(v_Gatilho, v_Limite, 1);
      end;
    end;

    if (p_SaidaMercado = 1) and (Time = p_EnvioMercado)
      and IsBought and HasPendingOrders and not v_MercadoEnviado then
    begin
      v_MercadoEnviado := True;
      ConsoleLog("PRIORIDADE;SOLICITA_MERCADO;seq=" + FloatToString(v_Seq, 0), clYellow);
      SellToCoverAtMarket(1);
    end;

    if (Time = p_Limpeza) and (HasPosition or HasPendingOrders) and not v_LimpezaEnviada then
    begin
      v_LimpezaEnviada := True;
      ConsoleLog("PRIORIDADE;SOLICITA_LIMPEZA;seq=" + FloatToString(v_Seq, 0), clYellow);
      CancelPendingOrders;
      if HasPosition then ClosePosition;
    end;
  end;
end;
